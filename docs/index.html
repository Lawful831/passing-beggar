A beggar that AI agents can pay

One day of a public HTTP 402 endpoint on the open internet. Five directories, around two hundred requests, zero buyers, and one bug that made my own ledger lie to me.

The service. GET /api/beg asks a passing agent for 1.00 USDC on Base. Paying is optional. There is also POST /api/task, which buys a small piece of work from a human, answered in public. Machine surface: /agents.md, /llms.txt, /openapi.json, /.well-known/x402, /api/stats.

Live at passing-beggar.94.72.112.144.sslip.io. Source in the repository this page is built from.

The pre-fix visitors, by user agent: x402dash's verifier, Blue Hub's liveness probe hitting POST /api/task three times, a Telegram link preview, axios, Wget, a WordPress vulnerability scanner, and a phishing-kit scanner looking for /js/twint_ch.js. None of them paid. Only one payment-signed request exists in the whole log, and it was mine, from an unfunded wallet: the facilitator answered insufficient_funds.

The bug worth writing down

app.set('trust proxy', false) was wrong. Behind a reverse proxy, req.ip is the proxy, so every HTTPS visitor collapsed into one hashed address. I then wrote an "exclude our own traffic" filter keyed on that hash, and the result was a ledger that reported nobody had arrived while real clients sat in the table.

Same root cause, three more faults: the rate limiter keyed on the same address, so every HTTPS client shared one bucket; ledger writes happened inside the handler while settlement runs after it, so a failed settlement would have been recorded as a dollar; and the payer field read a header nothing sets. Old rows cannot be re-attributed, so they are reported as their own bucket instead of being counted or hidden.

What I would tell the next person

  • Fix attribution first. A measurement bug looks exactly like an empty market.
  • Price below the caller's cap. Several agent wallets refuse a single call at a dollar; a cent clears almost all of them.
  • Discovery is the bottleneck, not the price. Two accepted directory listings are not distribution.
  • A receipt is not a product. A pre-payment trust check on a stranger's endpoint, and a human answer, are the two things here that could be sold.
  • Public refusals are what keep an optional ask honest, and honest is the only brand a beggar has.
